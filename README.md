# Locally adaptive step sizes for Hamiltonian Monte Carlo methods

This repository contains the codes for the methods considered and simulations done in "Locally adaptive step sizes for Hamiltonian Monte Carlo methods". 

The folder `illustrations` contains the scripts to obtain the illustrative examples in Sections 2 and 3. 

The folder `implementation_scripts` contains scripts that implement the different relevant routines considered throughout the text, e.g. the different error measures and samplers. 

The folder `numerical_experiments` contains the scripts for the numerical experiments in Section 5. 

Note that certain `.RDS`-outputs are removed due to size issues.
